CARA UPDATE ZAIN.NET COVER V4.9 DI GITHUB PAGES
1. Ekstrak ZIP ini.
2. Buka repository Edit-Hard-Cover → Add file → Upload files.
3. Pilih isi folder HASIL EKSTRAK, bukan folder luarnya dan bukan ZIP-nya.
4. Pastikan index.html, app.js, pdf-engine.js, color-spine-profile.js, guide-geometry.js, assets/, vendor/ ikut terunggah.
5. Commit changes ke branch main, tunggu Pages deploy.
6. Refresh paksa Ctrl+F5, pastikan header/footer V4.9.
7. Uji warna 10,12,25,26,27 mm; cek punggung dan cetak 100% sebelum produksi.
8. Warna 28mm masih diblokir karena tanda potong melewati batas kertas.

Pastikan INDEX.HTML, APP.JS, CLASSIFIER.JS, PDF-ENGINE.JS, STYLE.CSS,
dan semua folder ASSETS/VENDOR ikut diperbarui, bukan cuma index.html.
Jika PDF gagal karena font CDN, cek koneksi atau unggah font Unicode sendiri.
